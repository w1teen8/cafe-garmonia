# Кафе "Гармонія" — сайт кафе

Прем'єрний односторінковий сайт для кафе "Гармонія" (Боярка, Україна). Next.js (App Router) + TypeScript + Tailwind CSS v4 + Framer Motion + GSAP + Lenis, зібраний як статичний сайт для GitHub Pages.

## Технології

- **Next.js 16** (App Router, static export)
- **TypeScript**, **Tailwind CSS v4**
- **Framer Motion** — мікроанімації, reveal-ефекти, магнітні кнопки
- **GSAP + ScrollTrigger** — синхронізація з плавним скролом
- **Lenis** — плавний інерційний скрол
- **Lucide** — іконки

## Розробка

```bash
pnpm install
pnpm dev       # http://localhost:3000
pnpm build     # production-збірка (out/)
pnpm lint      # ESLint
```

## Контент і CMS

Весь контент сайту зберігається у JSON-файлах у `src/data/` — редагувати можна без зміни коду компонентів:

| Файл | Що містить |
|---|---|
| `menu.json` | Категорії та страви меню (ціни, опис, фото, `signature: true` для фірмових страв) |
| `gallery.json` | Фото галереї (категорія: interior / food / coffee / events) |
| `events.json` | Картки подій (дні народження, банкети тощо) |
| `reviews.json` | Відгуки гостей для каруселі |
| `faq.json` | Питання/відповіді для акордеону |
| `settings.json` | Бренд, контакти, адреса, години роботи, соцмережі, статистика |

## ⚠️ Дані, які потрібно замінити перед публікацією

Сайт зібраний із **правдоподібними плейсхолдерами** — реальних даних кафе на момент розробки не було:

- **Фото** — усі зображення взяті з Unsplash (тематично підібрані та перевірені вручну). Замініть на реальні фото інтер'єру, страв і кави в `src/data/*.json` та `src/components/sections/Hero.tsx`.
- **Контакти** — телефон, email, адреса та посилання на соцмережі в `src/data/settings.json` вигадані. Google Maps посилання та координати — реальні (взяті з наданого посилання).
- **Меню та ціни** — орієнтовні, для наповнення макета.
- **Форма бронювання** (`src/components/sections/Reservation.tsx`) — повністю клієнтська, без бекенду: після заповнення показує підтвердження, але заявка нікуди не надсилається. Потрібно підʼєднати реальний обробник (API-роут, Formspree, Telegram-бот тощо) — статичний експорт на GitHub Pages не підтримує серверні API-роути Next.js.

## Деплой на GitHub Pages

Сайт налаштований на статичний експорт (`output: "export"` у `next.config.ts`) з `basePath`, що вмикається змінною середовища `GITHUB_PAGES=true`. Workflow `.github/workflows/deploy.yml` збирає та публікує сайт автоматично при push у `main`.

Щоб деплой запрацював, в налаштуваннях репозиторію на GitHub: **Settings → Pages → Source → GitHub Actions**.
